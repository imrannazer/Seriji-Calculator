## Primary Color Palette
- Deep Islamic Green: `#0F2D20`
- Dark Accent Green: `#0B2016`
- Siraji Gold: `#D4A843`
- Radiant Light Gold: `#F3D78A`
- Warm Cream Background: `#F8F4EE`
- Off-White Surface: `#FDFBF7`

## Structural Components
- **Header**: Fixed height, rectangular, touches top/left/right screen edges. Contained mosque architecture silhouette. Left hamburger icon, centered title + icon, right Siraji emblem.
- **Footer**: Floating navigation bar detached from edges with rounded corners. Features an authentic raised Islamic pointed arch (Mihrab) for the active destination that animates between tabs.
