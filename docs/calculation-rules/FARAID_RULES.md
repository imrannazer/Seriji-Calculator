# Siraji — Faraid Calculation Rules Documentation

## Purpose
Document all Islamic inheritance jurisprudence sources and rules before implementation.

## Sources
- Quranic injunctions on inheritance (Surah An-Nisa: 11, 12, 176).
- Classical Hanafi, Shafi'i, Maliki, and Hanbali inheritance treatises (Al-Sirajiyyah fi al-Faraid).
